# Kurumi Theme for GitHub

Dos temas para GitHub inspirados en Tokisaki Kurumi, siguiendo la estructura
de [doki-theme/doki-theme-github](https://github.com/doki-theme/doki-theme-github).

## 🩸 Temas disponibles

| Tema | Estilo | Paleta |
|------|--------|--------|
| **Nightmare** | Oscuro | Carmesí `#ff003c` sobre negro `#050000` |
| **Day** | Claro | Rosa `#d91e42` sobre blanco `#ffffff` |

Ambos incluyen el sticker de Kurumi en la esquina inferior derecha.

## 📦 Instalación

1. Instala la extensión [Stylus](https://add0n.com/stylus.html) para tu navegador.
2. Abre el archivo `.user.css` que quieras instalar en modo **Raw**:
   - [Nightmare (Dark)](https://raw.githubusercontent.com/tu-usuario/kurumi-theme-github/main/themes/kurumi_nightmare.user.css)
   - [Day (Light)](https://raw.githubusercontent.com/tu-usuario/kurumi-theme-github/main/themes/kurumi_day.user.css)
3. Stylus te mostrará la página de instalación. Pulsa **Install Style**.
4. Para cambiar entre ambos, desactiva uno y activa el otro desde el panel de Stylus.

## 🖼️ Sticker

El sticker se carga desde `assets/kurumi_sticker.png`. Si quieres cambiar la
imagen, sustituye ese archivo o edita la URL en la sección `/* Sticker */` de
cada `.user.css`.
