## 📦 Instalación

1. Instala la extensión [Stylus](https://add0n.com/stylus.html) para tu navegador.
2. Ve a `themes/kurumi.user.css` y abre el archivo **Raw**.
3. Stylus te mostrará la página de instalación. Pulsa **Install Style**.

También puedes copiar el contenido de `kurumi.user.css` y pegarlo en
Stylus → *Create new style*.
